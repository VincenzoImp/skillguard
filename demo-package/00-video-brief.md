# Video Brief

## Audience

Hackathon judges who need to understand the need, the product, the demo, and the
technical credibility quickly.

## One-Sentence Pitch

SkillGuard is a wallet firewall for AI agents: it lets agents request onchain
wallet actions while the wallet owner controls what is allowed automatically,
what requires consent, and what is blocked before signing.

## The Need

AI agents are becoming capable of operating on blockchain. They can research,
monitor, route, trade, report, and automate. But the moment an agent needs a
wallet, the user faces a bad tradeoff:

- Give the agent a wallet or signer and risk real funds.
- Fund a separate wallet and still risk those funds.
- Manually approve every transaction and lose the benefit of autonomy.

SkillGuard fills the missing layer: user-owned consent and policy between the
agent and the wallet.

## Demo Promise

In under three minutes, show:

1. A user connects a wallet.
2. The user pairs Research Agent by QR.
3. The agent asks for a safe zero-spend action.
4. The agent asks for a paid `0.001 SOL` report that requires mobile approval.
5. The wallet signs only after approval.
6. A larger `0.05 SOL` request is blocked by policy.
7. The user can revoke the agent.
8. A Solana devnet receipt proves the decision path is real.

## Desired Tone

Calm, credible, technical, and urgent. Avoid hype. The product should feel like
infrastructure for the next wave of onchain AI agents.
